# Pawse artwork

The artwork in this directory and the Pawse icon set in `../icons/` were created specifically for this project. The cat, dog, README banner, and square project image were produced with OpenAI's built-in image-generation workflow and contain no third-party stock assets.

The artwork is distributed under the repository's [MIT License](../LICENSE).

| File | Use |
| --- | --- |
| `cat-detour.webp` | Cat illustration shown on the local detour page. |
| `dog-detour.webp` | Dog illustration shown on the local detour page. |
| `github-banner.png` | Panoramic README artwork. |
| `github-square.png` | Square project and social artwork. |
